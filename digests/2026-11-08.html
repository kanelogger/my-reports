宝玉 @dotey

主题：把纽约时报的 Dario 人物稿搬给中文读者 原链接

他摘要了《纽约时报》11 月 5 日那篇 Anthropic CEO Dario Amodei 的长篇人物稿，稿子赶在公司本月上市前发出。记者采访了二十多位同学、朋友、老师和同事，还看到早年邮件和 OpenAI 内部消息；Dario 本人通过公司发言人拒绝受访，所以多数故事来自别人的回忆。说法归结起来是：他年轻时泡在理性主义和有效利他主义两个圈子里，认定 AI 危险到只有他和想法相近的人才值得托付去造。朋友和同事认为，这既推动他抢在不在乎安全的人前面把 AI 造出来，也让他想把技术掌控在自己手里。

摘要里还有几处硬细节：2006 年父亲因丙肝去世，强化了「时间有限、要造工具」的念头；2007 年读完《奇点临近》后对同学说奇点可能在 2040 年前到来；在 OpenAI 期间立场变硬，曾想挡住 Greg Brockman 参与 GPT，Altman 没有答应，他和 Daniela 等人于 2020 年 12 月离职，四周后创办 Anthropic。原文在原链接，文中也链到 Dario 9 月那篇呼吁放慢前沿发展的原链接。

同日他又提醒，用 GPUI 之前先看自己踩过的坑：复杂 UI 多半要 fork，无障碍和键盘操作别扭，Rust 编译又吃 CPU 又吃磁盘，而且没有热更新，改一点界面都得等好几分钟，Agent 用 computer use 验收也又慢又贵。原链接 另外还说 Mac 上能玩《燕云十六声》，接 Xbox 手柄体验不错。原链接

我的看法：这篇稿本身就标明多数是他人回忆，当人物志读可以，当「Dario 内心独白」不行。上市前发这类画像，更该分清哪些有邮件和内部消息撑着，哪些只是旧同事口述。

Frank Wang 玉伯 @lifesinger

主题：AIE 大会印象，以及 Instagram 教他看产品和人性 原链接

过去两天他在上海参加 AIE 2026，说有一种很久违的技术大会感觉。印象最深的反而是全场可能最不技术的四场：Cursor 前设计师 Ryo Lu 的分享、他自己的分享，以及 Koji 和戴雨森参与的两场圆桌。他根据现场录音和笔记整理了一篇原链接，并写「期待让焦躁的创业者们，更焦躁些」。

另一条把资源约束写得很死：Instagram 人数始终比 Facebook 做同等功能的人少很多，被收购后也是如此；Facebook 曾投入 10 倍人力想把 Instagram 干死，最终证明大钱能收购团队，大力却出不了奇迹。他觉得模型领域资本抱团还能理解，应用领域却也很容易出现一家起、万物落，真正有非共识的创业者和机构都很少。原链接

夜里他又写了读完《解密 Instagram》的感想：Instagram 是为美而生的应用，增长路径是先抓住热爱的用户，再吸引品牌和名人，最后成为主流。书里能看到朋友圈、微博转发和抖音造星的影子。他也想到 Manus：在 Meta 只容得下一个 CEO，对 Facebook 有威胁的事都做不成。他还说 Instagram 从第一天就是社区而不是工具；Vibe Coding 的实质是单机游戏，只有极少数人能把它变成无限游戏；personal agent 帮人省下时间之后，大概率并不会拿去继续用 personal agent。原链接

我的看法：「大力出不了奇迹」说得准，但别把 Instagram 的小团队神话当成普遍规律，它后来靠的是 Facebook 的分发。边缘开花成立，规模化和分发仍然是另一道题。

郭宇 guoyu.eth @turingou

主题：图视频中台里，API 自由度和云 GPU 不是一回事 原链接

他在做几个垂直化个人代理，都要用到图像和视频生成，所以不得不在中台层解决调度。他的观察是：ComfyUI 云服务能给更大的自由度，fal 这类线上 API 则完全按商业化逻辑和成本来控制。这不只是成人内容问题，而是所有生成都无法完全自由；各家对这条基线的理解也不一样。Claude Code 的办法是用脚本和预剪辑在导演层对齐，无论底层是 ComfyUI 工作流还是线上 API，都先追求输出一致。但要让不同导演模型打分接近，前提是有一台本地机器，不断用导演模型反复审阅。

结论是：如果有大规模需求，又要高度一致的长视频，租用云 GPU 几乎是唯一选择。另一条则在想象，Claude Code 的云项目如果不是强制自动权限模式，而能改成 bypass permission，一晚上能做多少事。原链接

我的看法：商业 API 的内容策略和安全基线不一致，做多模型调度的人都会撞上。可「大规模一致长视频只能租 GPU」说得偏满，小规模或能接受平台审核的产品，API 仍然更省事。bypass permission 能加快速度，也会把误删和误推的爆炸半径一并放大。

Nous Research 发布 Arete-27B，把 Qwen3.8-27B 的「宣传标记」从约 22% 压到约 1%

Nous Research 在 Qwen3.8-27B 上做了监督微调，模型名 Arete-27B，目标是「在中国训练的模型上强化西方价值观」。他们自建 803 道题，覆盖言论自由、国家意识形态、市场与国家、教育、隐私监控、民主和环境等七类，再用约 5280 万 token、两次 epoch、1202 步完成训练，没有强化学习，也没有改结构。按官方说法，带宣传标记的回答从 22% 降到约 0.9% 到 1%，事实分从 2.32 提到 2.98（满分 5）；通用能力 Hermes Bench 从 65.77% 到 65.60%，他们称为噪声，Terminal-Bench-2.1 从 67% 到 70%。权重、数据和评测已公开。需要记住：裁判是他们选定的 LLM，外部尚未复现，且与对照模型的解码温度并不完全一致。

Anthropic 详解 Agent 记忆：笔记、显著性，以及用「做梦」回看日志

Anthropic 于 11 月 6 日发表工程博文《The components of agent memory》。他们把 agent memory 定义为 Claude 从用户互动和任务里得到、并能跨会话保留的知识，通常存成以后可以读的笔记；它不等于改权重，也不等于单次对话里的上下文学习。文中把「做梦」（dreaming）写成一种空闲计算：回看日志、纠正错误笔记、建立 wiki 式索引，并把少量内容提升到下次会话预加载的一层。评测里，较强的 Claude 会在 CL-Bench 上把验证过的规则写进记忆；玩《口袋妖怪红》时，Sonnet 3.7 写了 413 个记忆文件只拿到 1 枚徽章，Fable 5 只写 9 个文件却拿到 4 枚。他们还用收购来的 Stainless 约 35 万份内部文件做实验，128 轮 dreaming 后，25 道题得分从 13% 升到 48%，wiki 加搜索好于只用搜索。这是设计讨论，不是单独上线的消费级按钮。

Claude Design 独立站将于 12 月 14 日关闭，功能并进 Claude

Anthropic 帮助中心确认，原链接 这个独立站点将在 2026 年 12 月 14 日关闭，之后只读、不能新建项目。设计、原型和幻灯片会作为 Artifact，在 Claude 聊天、Artifacts 页和 Claude Code 里继续用。设计系统可以现在迁移；项目迁移仍在向付费计划逐步开放。原站点里的聊天和评论无法迁移，关闭后会按数据保留策略删除，旧的公开分享链接也将失效。中文圈今天也有人提醒备份。
