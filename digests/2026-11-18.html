宝玉 @dotey

GPT-6.2 能用在哪、要不要另付钱： 他根据官方博客整理了一版用法。OpenAI 11 月 17 日发布两款 GPT-6.2：Astra 接替 GPT-6 Astra，对标 Claude Fable 5.2；Sol 接替 GPT-6.1 Sol，当日常主力。他说中间档 GPT-6.1 Terra 和最便宜的 GPT-6 Luna 这次没有更新，这一点官方博文没有单独写，只是没有宣布这两档。Plus、Pro、企业版和教育版从当天起就能在 ChatGPT Work 和 Codex 里选用，不必另付钱；普通聊天界面里没有，要进 Work。企业版和教育版要管理员先打开。API 上 Astra 输入输出比上一代便宜 20%，缓存输入便宜 60%；Sol 价格不变。原链接

他注意到差评来得很快： 模型刚上线几个小时，他就看到不少说 GPT-6.2 不好用的帖子，并调侃不知道是真的糟糕，还是 Anthropic 花钱了。这是观察，不是评测。原链接

转述贝索斯谈接班人： Jeff Bezos 在 Semafor 采访里建议英伟达董事会从内部选人，理由是这家公司太复杂，空降 CEO 成功的机会「小到几乎没有」，只能当最后一招。该不该请回黄仁勋，贝索斯说外人不知道董事会里发生了什么，回答不了，但仍称黄仁勋值得钦佩。主持人拿亚马逊交给 Andy Jassy 作比，贝索斯认为不恰当，因为那次交接筹划了好几年。原链接

我的看法： 用法整理比情绪贴有用，尤其是「不在普通聊天里、要进 Work」这种容易踩坑的细节。差评来得快并不自动等于模型差，也不等于有人买水军，现在更缺的是可复现的对比，而不是立场站队。贝索斯那段同样没有给答案，只是把「空降几乎不可行」说得很硬。

AI 资讯

OpenAI 发布 GPT-6.2 Astra 和 Sol： 官方定位 Astra 为最难项目的旗舰，Sol 为日常主力。Plus、Pro、Enterprise 和 Edu 用户即日起可在 ChatGPT Work 和 Codex 中使用，Enterprise 和 Edu 需要管理员打开；开发者可通过 API 调用 gpt-6.2-astra 和 gpt-6.2-sol。Astra 的 API 标价为每百万 token 输入 8 美元、缓存输入 0.40 美元、输出 40 美元，输入输出比 GPT-6 Astra 低 20%，缓存输入低 60%；Sol 沿用 GPT-6.1 Sol 的 2 / 0.10 / 10 美元。Pro 500 两款都可用 Ultrafast，Pro 200 首次对 Sol 开放 Ultrafast。官方称在 Agents’ Last Exam 上，Astra 比 GPT-6 Astra 高 5.2 分、成本不到三分之一，比 Claude Fable 5.2 高 5.5 分、成本约 5%，但脚注写明 Fable 5.2 的榜去掉了 9 个使用了 fallback 模型的任务。它还称 Astra 是「科学研究最好的模型」。两款模型在网络安全能力上达到其 Preparedness Framework 的 Critical 阈值，因此加严了高风险协助，这也会限制一部分正当的漏洞研究。以上评分和「最好」都是 OpenAI 自己的表述。原链接

黄仁勋发布辞职后的首份书面声明： 他感谢过去一周的支持，回顾 53 年前来到美国并把英伟达称为毕生工作，随后写明：自己未能达到公司对每个人要求的标准，在个人生活中犯了严重错误，给董事会造成了麻烦，对此感到后悔，愿意完全承担责任，并配合董事会的独立调查。至于复职，原文是：如果董事会认为他回来符合股东、员工、公司和美国的利益，他会以回去担任 CEO 为荣。这不是已经回归，调查也还没有结束。原链接
