人物

宝玉 @dotey

主会话负责调度，Thread 再用更强的模型： 他认为「主会话 + Thread」若设计得当，Token 并不一定会爆。主会话更像前台，职责是甄别和路由，Sonnet 5.5 这一级就够；真正干活的 Thread 再用更强的模型，或者按任务难度选模型。他以自己用的 Claude Project 为例，主会话是 Sonnet 5.5，子任务是 Opus 5.5。主会话消息稀疏、缓存容易过期，过期后不应把全部历史和工具调用再推一遍，而是只带最近几条，再配 Session 检索。Thread 更像传统密集会话，缓存利用率高，但也应在缓存即将过期时先压缩上下文。原链接

和「强模型直接调度」并不矛盾： 有人说具体科研任务该由强模型来计划、调度和验收。宝玉认为那是任务内部的事。在 Grok Bot 这类应用里，用户把各种消息丢进同一个主会话，主会话识别后再新开 Thread，把原话转给 Thread 去执行。他打了个比方：前台不必懂数学，认出这是高难度课题后，把任务交给数学专家（比如 Fable）去计划和验收，专家再找 Opus 这类模型做具体执行。原链接

转述 Altman 谈黄仁勋该不该回来： 在 Yahoo Finance 采访里，主持人问黄仁勋该不该回归，Altman 说自己知道的还不够多，回答不了。他称黄仁勋一直是心目中的英雄，「英雄也有缺点」，并说很难想象没有黄仁勋的 AI 革命。主持人提到英伟达曾为 OpenAI 在俄亥俄州数据中心提供高额担保，这是主持人本场的表述，并追问担保现在是否还一样值钱。Altman 说市场仍然信任英伟达的担保，需求也还在，但反复强调黄仁勋的角色很难替代。该不该回来，他没有再给判断。原链接

我的看法： 把前台和执行拆开，比让一个最强模型包办所有闲聊更贴近真实账单；Altman 这段采访的信息量其实不大，回避本身说明交割之后的权力和担保关系，现在还没有人愿意当众说死。

我的看法： 这两条放在一起很能说明现在的别扭，模型能力已经强到让人愿意忍受封号和半成品工具，可这种忍耐不会无限持续，账号和任务状态这类基础可靠性，比再堆一个新功能更紧迫。

Orange AI @oran_ge

他想聊的一个判断是，AI 基建也许已经走完了： 他发预告说晚点讨论，并问「可以这么直白的吗」。这是话题预告，不是对新数据的论证。原链接

他质疑 Gemini Argon 和 Carbon 是不是都有 12T 参数： 这条是疑问句，没有给出出处。DeepMind 的模型卡确认二者是稀疏 MoE、1M 上下文，Carbon 在 Argon 基础上用更多思考 token，但没有公布 12 万亿这个数字。原链接

我的看法： 「基建走完了」眼下还对不上今天的新闻，TensorWave 刚宣布要为 OpenAI 建设 457 兆瓦，更像是建设周期换档，不是收工；12T 这种参数传闻在官方模型卡出来之前，先当成未证实的问题即可。

karminski-牙医 @karminski3

上手测了刚刚上线的 Qwen4-Max 正式版： 他用原图或原始视频，让模型用 three.js 还原界面，觉得空间理解有提升，面板按键也能对上，VLM 表现可圈可点。他认为拖后腿的反而可能是 three.js 缺少大力后训练，复现不够炫，但幻觉也更克制。测试里它的 thinking 比较省 token，很快进入正文，详细评测他说稍后会发。这是个人用例，不是官方基准。原链接

我的看法： 用「看图还原成可运行的 3D 界面」来压测空间理解，比只看聊天截图有用；不过单次还原成功还不能说明稳定性，等他后续对比和失败案例出来，会比今天这组示例更有参考价值。

歸藏(guizang.ai) @op7418

第十期 Next Token 把 Personal Agent 的难点讲清楚了： 这期节目谈黄仁勋辞职、Fable 和「语言即世界」，他特别推荐关于 Personal Agent 的部分，并用 Gemini 4 整理了几条放在图里。他的判断是，上一代移动互联网把围墙筑得太高，个人 Agent 很难做事，尽管内容侧其实已经有 YouTube 这样的入口。完整节目在 YouTube。原链接

上线了 Next Token Skill，方便按时间轴切片段： Skill 自带时间轴，讨论完某段内容后，可以让 Agent 导出对应视频，再发到其他平台。仓库在 GitHub。原链接

我的看法： 「围墙太高」说的是分发和权限，不是模型不够聪明，这个判断比再唱衰个人助手更站得住；Skill 适合他们自己的播客分发，换成别的长视频源，时间轴和授权才是真正的门槛。

阑夕 @foxshuo

Steam 和 Epic 为游戏是否必须披露 AI 公开对上了： 他转述双方立场：Steam 现行政策是，成品里只要 AI 介入了图像、声音、剧情或对话生成，就必须声明。Epic 的 CEO 唱反调，认为强制披露会变成耻辱标记，让玩家还没玩就先定性，攻击的是开发过程里的选择，而不是成品质量。Steam 员工的回击是，你不在意不等于别人不在意，这是基本的知情权。阑夕把两边都摊开，问读者更认同哪边。原链接

我的看法： 知情权和「免于被预判」并不完全互斥，真正该争的是披露粒度和位置，比如是在商店页强制标注，还是把细节放进制作名单，而不是在「全盘公开」和「什么都不说」之间选边。

郭宇 guoyu.eth @turingou

hayabuild 的缓存命中率接近 100%： 他说调了几天后，一个 iOS 项目构建只要 38 秒，就能自动打成 TestFlight 内测包，下一步打算开放名额给别人用。数字来自他的实测截图，不是对外基准。原链接

我的看法： 38 秒能进 TestFlight，说明他把重复编译的浪费压得很低，这对日更内测很有价值；对外开放后，更值得看的是多项目隔离和失败回放，而不是把命中率再往小数点后堆。

Tw93 @HiTw93

用家里旧设备搭了一套 Agent 测试集群： 主力是今年买的 Mac M5 Pro（48 GB / 1 TB），只负责写代码、签名和发版。测试放到柜子里的 M2 Pro，避免 Agent 在主力机上抢鼠标和焦点；这台机器还插了 iPhone SE3，用 WebDriverAgent 把界面读成元素再按标签点，并用 Parallels 跑 Windows 11 ARM 虚拟机。另外有一台 8 GB 的 ThinkPad X1 测真实 x64、缩放、电池、SmartScreen 和 Defender，里面再开 Linux 虚拟机看 Pake 在 Wayland 上的表现；NAS 微主机跑 Debian 容器，专门处理 GNU/BSD 工具差异和 deb、rpm 打包。设备亮度调到最低、不休眠，他隔半个月重启一次。原链接

测试靠辅助功能树，不靠瞎点截图： 他自己写了两个小工具，ax 把窗口里的元素、文字和坐标打成文本，input 用 CGEvent 补右键菜单和输入框。截图只是兜底。为了把 GitHub Actions 里每月约 70 美元的 macOS 账单压下来，他在测试机上挂了近 180 个自托管 job，先用几秒钟的小任务查询主分支是否已经跑过完整测试，没有再派给本地。CI 和 Agent 会抢同一块屏幕，他就用带 noclobber 的忙闲标记和超时来排队。他说现在卡点已经不在机器，而在自己的注意力，并提醒不要把提效本身变成全职工作。原链接

Pake 可以把任意网站变成轻量桌面应用： 他另发一条英文介绍，粘贴链接再按 Create，就能得到独立窗口和图标，CLI 已开源四年。官网是 原链接 。原链接

我的看法： 这套「主力机只构建、测试机真动手」比再买一台更贵的笔记本更接近工程现实，忙闲标记也说明多 Agent 抢同一块屏幕是真问题；不过柜子里一堆永不休眠的机器，本身就是电费、散热和远程链路的长期成本，把注意力省下来之前，先把权限和回滚收紧更重要。

Frank Wang 玉伯 @lifesinger

他把「卖出去」看得比「做出来」更重要： 他写 AI 应用创业者越来越意识到，分发比做产品更关键，并举了 Facebook 靠校园邮箱、Instagram 靠 Twitter 和 App Store、拼多多靠微信群、抖音靠当年便宜投流的例子。眼下他把 Manus 的起步部分归到实力带来的运气和 Monica 的积累，Higgsfield 则靠社媒爆款，并认为 Muse 这类需要大量资金铺渠道的玩法，一般团队负担不起。他的结论是，可复制的增长办法一旦可复制，就会变成红海，找到暂时不可复制的渠道，可能是很多产品能卖出去的唯一办法。原链接

我的看法： 分发确实经常比功能列表更决定生死，但把「不可复制」当成唯一解也危险，因为它很难写成方法，只剩事后叙事；对大多数团队，先抓住一个暂时便宜的切口，比等待独门心法更实际。

我的看法： 把跨应用记忆从厂商会话里抽出来，这个方向是对的，200 条上限如果属实，也确实会绊住长期 Bot；不过「无损、全量、任何 Agent 都能接着聊」是很强的承诺，权限范围、失败重试和敏感信息落地方式，要比功能清单更值得先看。

清月已经不困了 @qingyue820

他概括领先者的理想状态： 在他看来，最理想的竞争是让对手仍保留一定发展能力，却始终无法摆脱对自己技术体系的依赖。这是评论者的策略分析，不是某一份新政策全文。原链接

我的看法： 把情绪从利益计算里拿开，讨论会清楚很多；不过「保持依赖」只是供给方的设想，现实里还有转口、国产替代和规则执行的缝隙，策略意图不等于实际效果。

AI 资讯

AMD 完成收购 World Labs，李飞飞出任首席科学家： AMD 11 月 16 日宣布交割，World Labs 团队加入，继续做基础模型研究，并和 AMD 工程师一起把模型侧的需求反馈到硬件、软件和系统。李飞飞担任执行副总裁兼首席科学家，直接向苏姿丰汇报。World Labs 的方向是生成和模拟可交互的三维环境，以及机器人学习与仿真。今年 9 月 28 日的协议稿写明，这是约 82 亿美元的全股票交易，交割公告没有重述金额。原链接

阿里正式发布 Qwen4-Max： 官方介绍总参数 2.4 万亿，每 token 激活 710 亿，比同规模的 Qwen3.8-Max 少激活约 25%，原生视觉，上下文 100 万 token。阿里自有基准 Work360 显示，在 High effort 推理下比 Qwen3.8-Max 少用 35% token，单任务平均成本约降 60%。模型已在 QwenCloud 的 Token Plan 和 API 上线，也可在 QwenWork、QwenStudio 使用，隐式缓存命中时输入价为每 100 万 token 0.075 美元。官方还说 Qwen4 系列更小的开源权重「即将」放出。这与 11 月 12 日的 Preview 不同，今日是正式版，模型 ID 为 qwen4-max。原链接 原链接

ChatGPT for Healthcare 加入更完整的计算机使用 Agent： OpenAI 说 Agent 可以在现有医疗软件里读屏、点击和输入，处理转诊、事先授权和文档搬运，并改进带引用的临床检索，同时新增 20 余个医疗插件。点名的合作或试点机构包括 Abridge、Ambience、Cigna Healthcare 和 CVS Health。官方安全评估称，325 项受评任务里 99% 被医生评为临床安全，这些数字来自 OpenAI 自己的评测，不是外部监管结论。组织侧需启用相应工作区设置，并在有 BAA 的前提下处理受保护的健康信息，数据默认不用于训练基础模型。原链接
