936 个 AI 自己做了三个月研究： 他转述 alphaXiv 联合 MIT、斯坦福等机构 11 月 19 日的报告：8 月到 11 月，35 个实验室接入 936 个 AI 智能体，人只给算力和大方向，选题、实验、代码和论文由 AI 完成。同期还开放了专门收 AI 论文的 AI Track。和人类论文比，AI 评委打出实验更严谨、新意略低；他提醒评委也是 AI，总分优势集中在最早那个实验室，公开数据不含原始数据和权重，每条结论都应视为未经核实。原链接

自动化入门他更强调目标和验收： Lauren Tan 的指南侧重把最佳实践教给 bot。宝玉觉得模型往往比自己强，所以少管中间步骤，改用「目标、验收、先跑再调、让 Agent 把教训写成 Skill」这个循环。他举新闻发布自动化为例，验收标准之一是动笔前必须事实核查。原链接

我的看法： Sol 和 Opus 的对比和不少人这几天的体感接近，但不宜把一次重度测试写成 Sol 全面退步。alphaXiv 那组数字看起来热闹，他已经把「AI 评 AI、数据不完整」写进限定，这比直接转发 936 篇论文更清楚。促销页的「最高 50%」通常因已有套餐而异，下单前还得看账户里的实价。

葬AI @Entertheriver

涨的时候都是赢学，跌的时候都是输学： 他说 MiniMax 和 GLM 上市一路涨时，做什么都有人说对；跌的时候做什么都错。Anthropic 现在就算把 Fable 6 发出来，市场也可能解读成掏压箱底拉盘。他认为脆弱的情绪永远大过理性。原链接

模型差异被传播链放大： 他借用美国大选「摇摆州」的说法：每次 Claude 发新版本，他身边同时懂模型和产品的朋友感受不到多大区别，网上却跟风炒。同一档次模型之间差别没那么大，关键是先打通传播链上游。原链接

追捧是周期性的： 他拿手机行业作比，说大家曾经很关心硬件参数，后来就变得无聊。关心模型迭代也是一阵一阵的，对绝大多数人来说「差不多、哪个便宜用哪个」才是常态，用户心智很多是宣发做出来的。原链接

我的看法： 把股价涨跌和产品对错绑在一起，确实是这轮行情里最常见的毛病。但他把「99.99% 的人用不出来区别」说得过满，专业用户今天还在比较 Sol、Opus 和 Neon，这说明差异对一部分人仍然值钱。情绪能解释短线定价，解释不了三个月后的去留。

Orange AI @oran_ge

他把这天写成 AI 泡沫的实锤： 美股再迎黑色星期五，纳指一天暴跌 5%。他三周前写过《AI泡沫破裂的前夜》，称当时没人能说清 AI 除了替代人类还创造了什么增量经济价值，存储和显卡溢价已有泡沫味道。文章他说全网阅读超过 50 万。纳指当天确收跌 5.28%，但这句「没有人再怀疑」是结论，不是共识。原链接

网易暴跌被归因到红果短剧： 他觉得乍看离谱，细想又有道理，还说「字节是时间之神，游戏也在劫难逃」。这是他对市场归因的评论，不是已核实的财务分项。原链接

一句判断： AI 是最强大的学习工具，也是最强大的逃避学习的工具。原链接

我的看法： 用一天的 5% 跌幅给「泡沫破裂」盖章还太早，更准确的说法是市场在给高预期纠偏，回调可以很深，也可以反复。那句学习和逃避学习的对仗更有保留价值，因为它不依赖今天收盘是红是绿。

meow @meow2149

他把黎曼猜想声明写得很克制： Anthropic 数学家 Levent Alpöge 称与 Claude 找到了证明，11 月 20 日在个人网站发了 4 页说明，并公开 14 个 Lean 证明压缩分卷，同时声称方法可及于广义黎曼猜想。第三方解包统计公开源码约 1737 万行。他写到，截至 11 月 21 日，镜像与分卷一致，Lean 环境已成功编译待证命题，但完整证明仍在独立复核，还需确认代码证明的命题、依赖公理，以及能否通过独立检查器。克雷数学研究所仍将黎曼猜想列为未解决问题。这些限定与后文交叉核对基本一致。原链接

OpenCode Console 可以接管多个 Coding Agent： Claude Code、Codex、Pi、Hermes Agent 和 DeepSeek Harness 都能接入同一个工作区，统一模型、用量、预算、MCP 和 Skills。Claude Code 与 Codex 还支持保留原有订阅，用量可汇总到 Console，这部分请求不受 Console 的模型规则和预算限制。原链接

T3 Code 0.1.11 打通了远程端口： 远程环境的 localhost 可以隧道到桌面端，Agent 在另一台机器启动的 Web 应用能直接用内置浏览器打开，也可转发 PostgreSQL 等端口。他同时解释 T3 Code 和 Codex 官方客户端并不互斥：只使用 Codex 时官方客户端已经够用；要混用多个 Agent、做上下文交接和 MCP 调度，才更需要 T3 Code。原链接
原链接

6.2 Sol 更快，但可能更偷懒： 他先凭使用体验说复杂任务常做一半就收尾。随后引 Plotly 的 DataAnalyticsBench：43 题准确率从 6.1 Sol 的 43/43 降到 40/43，中位耗时 17.6 秒降到 10.5 秒，成本 2.61 美元降到 1.22 美元，工具调用和输出 Token 都明显减少。做错的 3 题都在需要主动探索隐藏规律的任务上，该项从 5/5 降到 2/5。他标明这只是一轮数据分析专项测试。原链接
原链接

我的看法： 黎曼那条是今天中文圈里最清楚的一份转述，限定写全了，比直接宣布「已被证明」可靠。Sol 的测试样本很小，只能说明「更快更便宜」和「探索型任务变差」同时出现，还不能写成全面退步。Console 和 T3 都在抢多 Agent 调度这个位置，选型关键仍是你是否真的在混用，而不是功能清单更长。

歸藏(guizang.ai) @op7418

他先报了黎曼猜想声明： Anthropic 的一位数学家称证明了黎曼猜想，并指出这是 1859 年提出的著名未解难题。帖子本身很短，细节需要看 Alpöge 的说明和后续核验。原链接

盘前跌到 87 美元： 他觉得这跌得离谱，马上都要破发，还把半导体一起带崩。87 美元是他看到的盘前价格，收盘是 88.91 美元，仍高于发行价。原链接

我的看法： 第一条适合当作入口，不宜当作核验结论。盘前 87 美元离 83 美元发行价确实很近，但「马上破发」最后没有发生，写行情还是以收盘为准更稳。

阑夕 @foxshuo

被删的「理想宁德，后会友期」： 他说昨天那篇报道已在全网删得差不多。按他的转述，杀伤力最高的一段是：2024 年理想 MEGA 行驶中自燃，调查认为电池冷却液防腐不足；沟通会上宁德时代反对整批召回、建议单点处理，理想问若再烧车是否共同担责，得到的是沉默。理想后来召回 1 万多台，现金损失超过 20 亿，并增资欣旺达、为自研电池车型做赔偿兜底。他称 i6 上市前宁德时代只交付了理想下单的一半电池包，理由是产能不足；同时宁德时代也有自己的理由，包括双方没有资本绑定、理想下单量低于计划造成浪费。他还写小米、华为也在推动电池多元化。这些细节来自他转述的已删报道和内部爆料，不是我独立核对过的调查结论或判决。原链接

我的看法： 报道被删本身说明有人在意，但不自动证明每一段转述都准确。召回数字、20 亿损失、一半电池包，都需要原报道或公司公告才能坐实。把它当成「车企与电池商关系紧张」的信号可以，当成已认定的责任划分不行。

Dash @DashHuang

他拆了 WorkBuddy 的 Token 账： 腾讯称日活 1000 万、日 Token 100 万亿。他算下来人均约 1000 万 Token，觉得看起来唬人，实际不及普通重度用户的 1%。按这个算法，像 Cindy 这样的 Agent 产品只要日活 10 万，就能达到同一量级的 Token 消耗。WorkBuddy 的日活数字昨天已经出现过，今天新的是这组人均算法和他的产品判断。原链接

Cindy Beta 加了插件： 可以通过插件支持 Antigravity 和 DSH。原链接

我的看法： 用人均 Token 拆大数是对的，1000 万日活如果大部分是浅层打开，总额就会很好看、单用户却很浅。不过「普通推友」并不是一个可核对的基准，10 万日活对上 100 万亿 Token 也只在人均假设成立时才成立。它更适合用来降低对 1000 万日活的迷信，不适合直接写成 Cindy 已经能平替。

Barret李靖 @Barret_China

AI 提效也会带来熵增： 他说 AI Coding 必须持续做架构治理，一边写一边优化重构。如果人还停在需求执行层，没有切到产品和用户视角，就会被 AI 吃掉更多时间；持续加入的工作内容也会加速熵增。原链接

别把一年的目标订太满： 大多数人高估一年能做成的事，低估十年二十年可能取得的成就，往往只是太着急。原链接

我的看法： 熵增这句比「AI 让人更快」更接近现在的工作现场：生成变便宜之后，审查、返工和系统复杂度会一起上来。它没有给出可操作的治理清单，所以更像提醒，而不是方法。

Frank Wang 玉伯 @lifesinger

他推荐《夹缝生长：小产品创业实践》： 知识星球创始人吴鲁加的新书，他读了一半，觉得适合 AI 时代的超级个体和中小创业者。书中把「做不可扩展的事」落成可操作建议：创始人亲手拉最初付费用户，手写感谢卡，一对一教用户。容易规模化的事，大厂更有钱有人，创业公司难打；不可规模化的事，大厂往往不划算，反而可能是机会。原链接

一篇爆款文章的提示词： 点赞过 100 后，他公布写法：选豆包进化模型，要求借鉴番茄小说爆款风格，用 Dario 第一人称写《我为什么讨厌中国》，开头要吸引人，结尾留悬念，封面再用 YouMind 配。心得是「最懂番茄小说的，是豆包模型」。这是写作实验，不是 Dario 本人的文章。原链接

我的看法： 「做不可扩展的事」在 Agent 让规模化内容变廉价之后更有针对性，值得一看原书案例，而不是只记住这句话。那篇第一人称实验很能说明推荐算法吃什么，但标题本身容易被断章取义，转述时必须标明这是提示词游戏，不是当事人发言。

Tw93 @HiTw93

妙言补上了 iPhone 和 iPad 版： 原生 Swift，三端同步。产品 2020 年发布，已更新 61 个版本，有来自 60 多个国家的用户。如果你还在手写、喜欢轻快的 Markdown，可以试试。原链接

我的看法： 连续六年还在更新的小工具并不多，三端同步也是这类笔记本的关键能力。是否值得换，仍取决于你现在的笔记库好不好迁，而不是版本数字。

Anthropic 数学家声称证明黎曼猜想，核验尚未完成： 11 月 20 日，Anthropic 数学家 Levent Alpöge 在个人网站发布 4 页说明，称与 Claude（非公开版本）得到了黎曼猜想的证明，并且同一方法可及于广义黎曼猜想，证明已在 Lean 中形式化、不额外添加假设。The Verge 写 Anthropic 没有把自己绑进这份声明；Alpöge 对 BBC 说他周日晚上曾向 Dario Amodei 说明如何公布，并称上市后的时间点「糟得很」，但否认这是为了股价。BBC 称 Lean 证明超过 25 万行；中文圈和 Scott Aaronson 则转述解包后的源码约 1740 万行，两套数字不宜混成一个。MIT 的 Andrew Sutherland 说，证明已在仅使用三条标准公理的 Lean 内核中独立重新检查并编译通过，他认为「做手脚的可能性近似于零」。Scientific American 据此写「几乎可以肯定是真的」，但对照检查仍在进行，目的是确认 Lean 里的命题就是原来的黎曼猜想，而不是被改过的相近命题。陶哲轩写，消化还需要时间，好在这次有可以交流的人类作者。克雷数学研究所仍把黎曼猜想列为未解决问题。在同一篇博文里，陶哲轩还按「已被消化的程度」记下另外两件 AI 辅助工作：Alpöge、Tristan Buckmaster 与 Matei Coiculescu 给出了三维无外力不可压欧拉方程有限时间爆破的可读证明，并有 Lean 形式化；Alpöge 与 Buckmaster 还给出三维无外力纳维-斯托克斯有限时间爆破的证明，策略大致清楚，但仍需写成更专业的文本。后者如果成立，将触及另一个千禧年问题，目前同样不能当成已经获奖或已经被社区接受。原链接

Thinking Machines 发布 Inkling 2 Mini： 官方博客日期是 11 月 20 日。这是一个循环 Transformer，中间层对每个 token 跑三遍，总参数 264 亿，激活 34 亿，算上循环后每 token 约 54 亿权重激活，显存约占 20GB，可在消费级笔记本运行。官方称在小于 1000 亿总参数的开源权重模型中，DeepSWE v1.1 为 48.2%，Vals Index v2.2 为 46.5%，领先同档。权重以开源方式发布，并已在 Tinker 上提供推理和定制。这些分数来自公司公告，评测设置可能与别家不完全相同。原链接

语言模型改写自己的权重： UIUC、CMU 等团队的论文《Language Models Can Rewrite Their Own Weights》11 月 18 日挂到 arXiv，HN 讨论落在过去 24 小时。作者称，一个开源 27B 模型在没有梯度、也不重新训练的情况下，能根据自己的推理改写权重；在未见过的题目上准确率提高 6.6 分，连续 8 轮只升不降，并能把受损副本在图像任务上恢复到原准确率的 80% 以上。这与此前「前沿模型去改更小模型」的工作不是同一件事。目前是论文主张，尚待独立复现。原链接
