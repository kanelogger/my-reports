  1. 模型OpenAI Decisions API 正式可用

    基于 GPT-6 Luna，面向分类、路由、打分这类有界答案，官方称比 Responses API 快约 10 倍，单请求最多 400 个问题，支持图文和原生 JSON，已对所有开发者开放 原帖，官网

  2. 产品Anthropic 把 Agent Skills 捐给 AAIF

    同日 Linux 基金会下的 Agentic AI Foundation 一口气收了四个项目：Anthropic 的 Agent Skills、OpenAI 的 Open Responses、Hugging Face 的 OpenEnv、阿里的 OpenSandbox，AAIF 托管项目从 3 个扩到 10 个。Skills 自去年 12 月已有 70 多家平台接入，号称 100 万个 skills、近 2.8 亿次安装 原帖，Linux 基金会

  3. 产品Google 推出 Agent Compute Engine，并预览 Gemini API CLI

    前者在 AGNTCon + MCPCon 上宣布，强调企业侧跑、管、扩 agent 的算力和治理；后者是给编程 agent 用的零依赖 Go 命令行，可从终端生成图像、视频、语音和音乐，并拉起 Deep Research 一类托管 agent，和给人用的 Gemini CLI 不是一路 原帖，Gemini API CLI

  4. 模型Anthropic 用 Claude 大规模做形式化验证

    和 Theorem Labs 合作，几周内在 100 多个真实开源库上证明安全属性，把以前只适合小代码库或靠专家手工做的形式化验证往工程化推 原帖，研究页
