  • 权重空间编程：Astra 直接改小模型权重：MIT CSAIL 四位研究者发博客，称前沿大模型可像读写代码一样读懂、修改甚至从零写出神经网络权重。用 GPT-6 Astra 只动 Qwen3.5-0.8B 的 0.016% 权重，MATH-500 从 7.9% 涨到 48.1%，约六倍；另有仿真小车改 3.5% 权重后 1,024 次全成功、从零写打砖块网络得分约是强化学习版的 20 倍。作者也写明条件：Qwen 开思考易陷入重复循环，删掉第 15／19 层某个方向才见效，且要允许练习题试跑约 50 次；换成很少循环的 Gemma 3 270M 则无提升。结论是改权重能去掉挡住能力的障碍，加不出本来没有的能力；目前多为作者自报，尚无独立复现 原帖
  • Pando vs Scion：Git 扛不住 Agent 写码：OpenAI 发文介绍自研 Git 后端 Pando，Anthropic 此前发 Scion。两边痛点一样，解法相反：OpenAI 保留 Git 协议只换服务器，推送中位等待约降八成、日分发近 1PB；Anthropic 自建客户端与服务器，CI 拉代码从几分钟变几秒、资源约降到原来的 1/200。提交量暴涨（OpenAI 合入约涨到十几倍、Anthropic 日合入数月内涨超 12 倍）让传统排队与现场打包失效。宝玉判断普通团队更近 OpenAI 路线，改进会回流上游 Git 原帖
  • baoyu-design 加 Motion：在 Claude Motion 上补多人协作与编辑器，渲染过程可边看边改，文字可随时编辑并接 Design System；可跑在任意 Agent，含 DeepSeek Harness 插件。他提醒效果别期望太高，仍要配擅长 Motion 的模型与 skill，但方向是「简单编辑器＋标记评论就能改」 原帖
  • Cat Wu 离职：Claude Code 与 Cowork 产品负责人发文称周五是在 Anthropic 最后一天，未说原因与去向；早年做过 Scale AI／Dagster 工程师，经 Index Ventures，2024 年 8 月加入 原帖
我的看法
权重实验最值得盯的是「去掉障碍 ≠ 凭空灌进新能力」这条边界，比六倍数字本身更能防幻觉；Pando／Scion 则说明 Agent 已经把源控从工具问题抬成公司基建问题。
