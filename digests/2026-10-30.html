  1. 模型OpenAI 即日起将 ChatGPT Pro 100／200／500 与 Business Premium 用量上限全部翻倍，并取消原定 Pro 200 降额

  2. 模型Anthropic 公开 Claude「自我评估」防滥用技术

    官方称 Claude 每次回答后会在后台做一轮简短安全评估，自 6 月起已在线上运行并抓到其他防线未覆盖的滥用；因复用已读对话的 KV cache，额外推理成本不到 2%，评估不向用户展示、不额外收集数据。详情见新 Safeguards 博客 原帖，博客，中文整理

  3. 模型Claude API Messages／Token Counting 单次请求上限从 32 MB 提到 128 MB

    ClaudeDevs 与平台 Release Notes 确认，面向官方 API 的长截图会话与大 PDF 约有 4 倍空间；文档亦写明超过 20 张图时单图边长上限放宽到 3000 像素。Bedrock、Vertex 等托管上限未同步调整 原帖，文档，中文整理

  4. 产品Google 编程助手 Jules 宣布收束，经验并入 Antigravity

    Jules 官方称异步编程 Agent 实验阶段结束，将把远程后台任务执行等能力并入 Antigravity，统一成 agent-first 开发体验，同时感谢用户用 Jules 修 bug、写测试与上线功能 原帖

  5. 模型Mistral 正式开源 Large 4（Le Chonk）权重

    官方称新版面向 agentic coding 与网络安全，FrontierCode 开源模型中排名靠前，并经 CrowdStrike、Cloudflare、Rubrik、Zscaler 等厂商测过；权重可在 Hugging Face 下载，可用 Mistral Forge 定制。Artificial Analysis 评其为中国以外开源权重里综合分最靠前之一，总参 1.05T／激活 52B，API 价约 $0.70／$2.10 每百万 token 原帖，评测

  6. 研究OpenAI 更新公开 Model Spec，强调更自主工作下的五项核心价值观
