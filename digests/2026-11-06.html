人物

郭宇 @turingou

主题：mokutori 上架，押注垂直个人代理中台 原链接

他发布今年第 22 款产品 mokutori：把 iPad 变成直连 Grokbot／Muse 的扫描仪，已上 App Store。起因是自己的刚需，公司法人文件、个人杂务和证件管理基本都丢给 Grok bot。App Store 页 原链接

同一天他把赌注说死：已经有大约十几个完全不同的垂直化个人代理在做，一旦中台打通，剩下就是找场景、设计入口和盈利，生意会像航空公司一样偏刚性需求 原链接 。实操侧，他用 Tuwa 操控手机号打电话退掉长期不用的 Anytime Fitness 会员 原链接 ；SandBank Agent 中台做好后，声称 15 分钟做出高完成度停车场投币计费应用，还能和其他个人助理联动 原链接

我的看法：mokutori 把「拍证件进 Agent」做成入口，比再讲一遍个人助理愿景更硬；中台故事值不值得信，要看这十几个垂直产品有没有一个真正留住付费用户。

Barret李靖 @Barret_China

主题：一晚提示词，把开源 Agent 栈拼成主动服务 原链接

他发了一段留给 AI 的提示词：在电脑上配置好 Pi、DSH、Super-Agent 等开源项目，组合成能主动提供服务的超级智能；并要求先充分探索现有 CLI、MCP、Skills、浏览器自动化，以及本地和云端 Agent。帖子互动很高（约 700+ 赞、上千收藏），但时间线 API 只返回了开头一段。

我的看法：热度说明「本地开源栈拼装」仍是中文圈刚需；不过提示词爆款不等于系统稳定，真正难的是权限边界和半夜乱调用。

宝玉 @dotey

主题：Skill 逆向、人事流动，外加 Claude 理财与 METR 原链接

他分享逆向 Claude Design Skill 的套路：直接问系统提示词会被拒，先让它用 Design Skill 做个最简单作品，再要求「做一个和你输入输出一样的 Skill」。后续他又把同一思路扩到 Claude Duet：先交一个 Skill 让它安装，再追问「为什么你可以安装」 原链接

人事侧继续跟：Anthropic 首位增长员工 Austin Lau 去 OpenAI 原链接 ；Thariq Shihipar 周五下午三点停用公司邮箱，到六点离职消息已在 X 传开，有人盯邮箱失效、有人在共用 Slack 里发现 原链接 。产品／研究侧他还拆了 Claude Personal Finance 和 METR 的加速评估（详见 AI 资讯）原链接 原链接

我的看法：Skill 逆向这招的价值不在「偷提示词」，而在逼 Agent 把行为暴露成可复用规格；邮箱失效监控则提醒你，圈子里的人事情报已经半自动化了。

Tw93 @HiTw93

主题：Kami 补上小红书社交图排版 原链接

他说 Kami 终于加上自己用了半年多的社交图功能，适合把内容排成小红书卡片；只要告诉 Agent「用 Kami 做成小红书卡片」，就能出漂亮效果，他还挑了 8 种底色。站点 原链接

我的看法：Agent 写得再好，发小红书仍卡在排版；Kami 这种「给 Agent 的设计系统」比再做一个聊天壳更贴近真实分发。

Orange AI @oran_ge

主题：写《AI泡沫破裂的前夜》，嘲讽供给不足避泡沫论 原链接

上周末他写了《AI泡沫破裂的前夜》，核心判断是：AI 目前主要在替代人类、从原有工作抢存量价值，还没有为人类创造增量价值。同日他给「数据中心建设放缓反而避免泡沫」的说法打了绿色满分，吐槽供给被砍就能让需求慢慢跟上的脑回路 原链接 。更早一条则转述零和游戏的麻烦：短期本能不积累，越依赖更大电脑和 AI，越可能被替代 原链接

我的看法：存量替代和增量创造这把尺子很有用，能把「模型更强」和「经济账变好」拆开；但泡沫文本身也容易被当成择时信号，别把它读成明天就崩盘。

歸藏 @op7418

主题：Omarchy 上 Apple Silicon，外加免费本地语音输入 原链接

他说很火的 Linux 发行版 Omarchy 4.5 终于支持苹果 M1／M2／M3 和 Neo，估摸 M4 也不远，等支持就把自己的 M4 Mac mini 刷成 Omarchy。语音侧他试了网易「叭哥说」：免费、本地 ASR 是自家模型，对比海外 Typeless 一类收费产品，觉得网易这些小 AI 工具最近都不错 原链接 。行情上他也跟了 AI 相关美股暴跌 原链接

我的看法：Omarchy 上 Apple Silicon 是把「刷机玩 Agent」的门槛往下搬；叭哥说这种免费本地输入，长期比又一个云端听写更有黏性。

一泽Eze @eze_is_1

主题：Chat Memo 正式发布，跨 AI 续聊 原链接

他宣布跨 AI 对话管理工具 Chat Memo 正式发布：实时备份电脑和网页上的 AI 聊天，换模型也能接着聊；支持 Mac／Windows，点名适合频繁换 Agent、跨 AI 接续任务，以及担心 Claude 封号丢记录的用户。昨日还在说小规模内测，今天改口正式发。

我的看法：正式发比内测安利硬一点，但「实时备份网页对话」的稳定性和隐私仍要自己验收，尤其是你真把 Claude 当生产工具时。

圖拉鼎 @tualatrix

主题：KYC 没做完又被 Anthropic 封号 原链接

他说 KYC 还没操作完，20 刀账号就被 Anthropic 封了，并调侃每次被封当天杭州天气都特别好。另两条分别问美股大跌是否意味 AI 泡沫破灭，以及吐槽国内家庭宽带多年不升级、上传仍是小水管 原链接 原链接

我的看法：封号叙事已经从「运气差」变成中文圈固定栏目，说明 Anthropic 风控和真实付费用户体验仍拧着；别把每一次封号都上升成产品战略讨论。

Frank Wang 玉伯 @lifesinger

主题：两种人类新世界，以及临场改 PPT 原链接

他不断推演 AI 应用创业者的可能性后，画出两张图，问大家喜欢哪一种人类新世界。白天在 AIE 上海分享前，他睡梦中觉得内容没讲到真心话，临场用 YouMind 重做 PPT，还说有 YouMind 改稿居然不慌 原链接

我的看法：两张图比口号有用，因为它逼你选默认入口和权力结构；临场改 PPT 则是个人工作流样板，别误读成「有了 AI 就不需要提前准备」。

AI超元域 @AISuperDomain

主题：agent-desktop 和 Auto-Ontology，给 Agent 补眼睛与数据语义 原链接

他推 Vercel Labs 开源的 agent-desktop：用系统无障碍 API 直接读 macOS／Windows／Linux 界面元素，把按钮、窗口、输入框变成带引用 ID 的 JSON，宣称不必再靠截图和像素匹配，仓库约 1.6 万 Star。地址 原链接

另一条是 NVIDIA 开源 Auto-Ontology：用语义图谱帮 Agent 理解数据库业务术语和表关系，而不是盲目生成 SQL 原链接 。仓库 原链接

我的看法：无障碍树比截图稳，语义层比「再提示一次写对 SQL」更接近企业落地；两者都还要看真实应用里的权限模型和误操作成本。

idoubi @idoubicc

主题：微信小微桌面版灰测 原链接

他截图称微信小微开始在桌面版灰测，并说中国的 personal agent 还是得看微信。

我的看法：如果桌面入口成立，国内个人助理的分发会被微信重新定义；现在还只是灰测截图，先别写成全面开战。

响马 @xicilion

主题：真正的低代码是 vibe coding 原链接

他认为工作流本身没有错，即便实现了 AGI 也仍需要工作流；错的是拖拽式低代码生产方式。现在正经程序员都不怎么手写代码了，行业趋势指向真正的低代码就是 vibe coding。

我的看法：把 vibe coding 抬成「真低代码」有一半道理，因为它消灭了拖拽配置的中间层；另一半风险是，没有测试和边界的工作流，只会把低代码的坑换成自然语言的坑。

AI 资讯

Thinking Machines 发布 Inkling 2 Small，AA Index 约 31，权重拟下周开源

第二代 Inkling 起步作：594B MoE、17B 激活，支持图像输入和可变努力程度；官方称在 agentic coding、视觉、知识工作和推理上相对上代有明显跳升，Artificial Analysis Intelligence Index 约 31 分。现已在 Tinker 提供推理与微调，权重暂未放，计划完成外部安全测试与红队后以 Apache 2.0 开源。原链接 原链接

Anthropic 上线 Claude Personal Finance：Plaid 只读连银行账户

美国 Pro／Max／Ultra 用户可把银行、信用卡、贷款和投资账户经 Plaid 接到 Claude，用自然语言问余额、花销和账单；访问只读，不能转账、管理或投资，官方也不按此给投资建议。Personal Finance 枢纽内的对话声明不用于训练模型。比 ChatGPT 同类能力大约晚半年，范围也更窄。原链接 原链接

METR：Anthropic 明确任务上的能力进步速度约翻倍，多归因 AI 参与研发

独立评估机构 METR 发布对 Anthropic 的高权限评估，判断截至 2026 年 10 月，其在「目标明确的任务」上提升模型能力的速度，大约是 2024 年 3 月到 2025 年 10 月的两倍（基准趋势约 1.9×，95% 区间约 1.5–2.8×），并认为当下大部分加速可能来自 AI 辅助研发，同时强调不确定性很高。报告还提到未见明确瓶颈会在未来 12 个月挡住进一步加速。原链接 原链接
