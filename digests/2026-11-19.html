人物

宝玉 @dotey

Anthropic 定价 83 美元一股： 他转发官方消息，Anthropic Class A 普通股发行价定为 83.00 美元，预计 11 月 19 日以代码 ANT 在纳斯达克开盘。更完整的发行规模见后文 AI 资讯，以公司新闻稿为准。原链接

马斯克把请走黄仁勋，比成公牛赶走乔丹： 他转述马斯克随总统访华时在 CNBC 对 Andrew Ross Sorkin 的谈话。马斯克说没有人能真正取代黄仁勋，他一个人干着好几个人的活，亲自管供应链，会和关键供应商在韩国、台湾一起吃路边摊，团队里很多人是因为对他的忠诚才留下。马斯克也说黄仁勋「确实犯了一些错」，但不认为他对美国不忠，公开称赶走他对股东不是好事。这是马斯克的个人判断，不是董事会文件。原链接

Kress 把「改任 CTO 或形象大使」也堵回去了： 他整理了 Jim Cramer 对临时 CEO Colette Kress 的追问。Cramer 提到董事会已表态不请黄仁勋回任 CEO，仍问在更彻底的调查之后，能否以不触碰监管红线的其他身份回归，并认为此前调查并不充分。按宝玉的转述，Kress 的答复没有留口子：黄仁勋已经辞职，董事会接受辞呈，也不会恢复他的职位，这就是官方立场，公司现在要向前看。原链接

Jason Wei 离开 Meta，去 Mercor 当首席科学家： 他写到，Mercor CEO Brendan Foody 在美国时间 11 月 17 日宣布这一任命，Jason Wei 随后发帖确认，说在 Meta TBD 实验室待了一年，并认为「数据会决定下一个前沿」。宝玉还回顾了他从思维链论文到 o1、评测基准的路径，以及 Mercor 刚完成 7.5 亿美元融资、估值 200 亿美元（这是 11 月 12 日前后已报道过的融资）。他同时指出，TBD 由 Scale AI 创始人领导，而 Mercor 正是 Scale 的主要对手。Jason Wei 没说离开原因，Meta 暂未回应。原链接

我的看法： 83 美元是可以核对的官方定价，马斯克那套类比只说明圈子压力还在，改变不了董事会已经公开的立场。Kress 把 CTO 和形象大使一并拒绝，比「暂不回任 CEO」更硬，但独立调查是否结束，这篇采访并不能回答。Jason Wei 去 Mercor，更像是评测和数据生意把人从大实验室里吸走，任命本身还缺少双方更完整的说明，不宜引申成 TBD 已经垮掉。

他先把 Neon 在 Antigravity 里的用法讲清楚了： Google 正在分批推送 Gemini 4 Neon，并加入 Orchestrator (Neon)。需要改代码时，Neon 先读代码、定计划，Hydrogen 接着改文件、跑测试。如果 Hydrogen 执行受阻，例如同一个验证步骤失败两次，任务会交回 Neon，由它检查状态、调整计划，再让 Hydrogen 继续。这和 Antigravity 官方说明一致。原链接

Claude 的 Linked billing 测试版： 在 Factory、Linear、Warp 等已支持的工具里使用 Claude API 时，费用可以记到客户自己的 Claude Platform 账上，不必把 API Key 交给这些平台。客户授权连接自己的组织后，由 Anthropic 直接收取这部分调用费用。官方文章见后文。原链接

T3 Code 和 Orca 怎么选： 两者都是开源的多 Agent 开发工具，都支持 Claude Code、Codex、Pi 等，也有独立工作区、任务委派和代码审查。他的区分是：T3 Code 更强调统一管理不同 Agent 和开发会话，Orca 的组织方式不同。这是选型讨论，不是跑分。原链接

我的看法： 他对官方功能的转述仍然比情绪贴有用，尤其是 Orchestrator 里「失败两次再交回规划模型」这种具体规则。Linked billing 的意义是把密钥留在客户自己的组织里，选型对比则还缺少一张能并列的功能表，读的时候把它当导购提纲，不要当评测结论。

Orange AI @oran_ge

Neon 的位置，他画得大体对，价格写漏了： 官方发布后他写道，Coding Agent 指标世界第一，Carbon 像 Fable，又慢文笔又好，Neon 像 Opus，综合能力最强，尺寸介于 Carbon 和 Hydrogen 之间，标价 3/15，「没有折扣」，并补了一句 Antigravity 太差了。Coding Agent 第 1 能对上官方的 Artificial Analysis Coding Agent Index（58.6）。但官方同时写了缓存输入 0.15 美元/百万 tokens，相当于 95% 折扣，「没有折扣」不成立。所谓各领域都是谷歌自家第一，官方总榜也只排到第 3。原链接

6.2 他觉得现在还行，问题可能在 Codex 的 harness： 他说自己用 Sol 和 Astra 6.2 体感还行，Tibo 曾提到三四天前的 KOL 测试版有严重问题，现在的版本其实还好。很多人反馈 Codex 里调用比较慢，Pi 和他们的产品 Cola 走 API 却很快，他怀疑是 Codex 的适配问题。这是使用观察，不是官方说明。原链接

我的看法： 把 Neon 放在 Carbon 和 Hydrogen 中间，这个产品位置是对的，可价格和「全面第一」已经写过了。如果 Codex 里明显更慢、同样的模型在别的客户端却快，那就应该先查客户端，而不是先给模型下判决。Antigravity 的槽可以留，它解释得了为什么有人宁愿自己接 API。

Barret李靖 @Barret_China

他要程序员接受「黑盒编程」： 他们团队有不少系统用 Rust 写，真正精通 Rust 的人并不多，其中还有高并发、高流量的系统，他们仍然敢让 AI 去开发。原因不是不管了，而是把精力转到需求、架构约束和验收：系统要具备什么能力，性能和稳定性到什么水位，哪些安全规范必须遵守，哪些测试必须通过，这些要先定义清楚。函数怎么写、代码怎么组织，很多时候可以交给 AI。复杂重系统的架构仍要盯，但工程师不必再看每一行。他的结论是，写代码正在从核心工作里退出，人要做的是理解业务，并建立能让 AI 持续交付的工程体系。原链接

他不赞成把「压缩人机轮次」当成目标本身： 很多团队把流程拆成需求、设计、开发、埋点、测试、性能优化，再统计每个节点要几轮交互，想把 10 轮压到 5 轮、3 轮甚至 1 轮。他认为，如果流程已经可以自动执行，AI 内部循环多少轮没那么重要，多试几轮有时反而能交出更正确的东西。真正该看的是人要介入多少次，以及最终交付质量。需求和验收清楚之后，中间执行应尽量让 AI 自己完成，优化的是一个需求从提出到合格交付，要消耗多少人的注意力。原链接

我的看法： 这两条比「AI 会取代程序员」有用，因为它把人的工作说成定约束和验收，而不是改词聊天。可黑盒有一个硬前提：出事之后，还得有人能读懂并修好那些生成出来的 Rust。如果验收只覆盖了高兴路径，高并发系统里的隐匿故障，会比少写几行代码更贵。

Proton Lumo 桌面版： Windows、macOS 和 Linux 可安装，新增连接器、计划任务和 Skills，可访问本地文件、执行 shell、抓取网页，也能接 Google Drive 或自建 MCP。Proton Mail 需通过 Proton Mail Bridge。原链接

Google AI Studio 的 Android 构建补上了后端： 生成的 Kotlin 应用现在可以接入 Google 登录、跨设备同步，并调用 Gemini。以前只能用本地会话存储，现在 Agent 会在用户确认后配置 Firebase。原链接

Magpie 的 MCP 路由： yetone 推荐用它管理大量 MCP 服务器，并称支持工具懒加载和智能编排。原链接

MyGo 0.10 与 Asuka 语言： 前者加上了 iOS 和 Android，后者把框架语言从 Go 换成自研的 Asuka，项目页为 原链接。原链接 原链接

04

Google 发布 Gemini 4 Neon： 11 月 18 日，DeepMind 和 Google 推出介于 Gemini 4 Carbon 与 Hydrogen 之间的新模型，强调在软件工程、知识工作和科学流程里更快完成端到端任务。官方定价是输入 3 美元/百万 tokens，缓存输入 0.15 美元/百万 tokens（95% 折扣），输出 15 美元/百万 tokens，上下文 100 万 tokens。当天起可在 Gemini API、Google AI Studio、Gemini for business，以及付费的 Google AI Pro / Ultra 用户的 Antigravity 和 Gemini 应用中使用。官方给出的数字包括：Artificial Analysis Intelligence Index 在 xhigh 思考档总分 61、总榜第 3，Vals Index 第 2（70.9%），Artificial Analysis Coding Agent Index 第 1（58.6），Zapier AutomationBench 第 1（56.3%）。Antigravity 同时提供 Orchestrator (Neon)，由 Neon 做规划、Hydrogen 做执行，执行受阻再交回 Neon。原链接 原链接

Anthropic 将 IPO 定价为 83 美元，预计今天以 ANT 开盘： 公司 11 月 18 日新闻稿写明，Anthropic, PBC 的 Class A 普通股发行价为每股 83.00 美元，发行总量 980,000,000 股，其中公司出售 956,351,354 股，原股东出售 23,648,646 股，公司不从后者获得所得。股票预计 11 月 19 日在纳斯达克 Global Select Market 以 ANT 开始交易，11 月 20 日交割，仍需满足惯例条件。承销商另有 30 天内最多追加购买 147,000,000 股的选项。按官方股数和发行价计算，公司自身募资约 793.8 亿美元，整场发行规模约 813.4 亿美元。媒体报道中出现的完全稀释估值未见这篇新闻稿，这里不采用。11 月 13 日此前只确认过开盘日、尚未定价，这次是实质进展。原链接

英伟达董事会公开排除请回黄仁勋： 美国时间 11 月 17 日的财报电话会上，董事长 Harvey C. Jones 说，董事会在 11 月 12 日宣布黄仁勋因个人行为与公司行为准则不符而辞去总裁、CEO 和董事后，已一致接受辞呈，并且不打算恢复他的 CEO 职务。随后临时 CEO Colette Kress 在采访中，把改任 CTO 或形象大使等假设也一并拒绝。这则表态出现在 11 月 18 日早报窗口前后，昨日简报未收录，今日补记。它确定的是董事会当前立场，并不等于独立调查或监管程序已经结束。原链接

Genie 4 向 Ultra 用户开放： 同一天，Google 更新 Project Genie，符合条件的 Google AI Ultra 订阅者可以首次使用 Genie 4。官方称可以在探索世界的过程中用文字改天气、加入角色或改写剧情，并第一次配上实时原生音频，包括环境声和角色对白。这次还升级了 Genie 3，增加了帮助搭世界的 Project Genie agent，以及可发现、再创作的社区画廊。原链接

OpenAI 称模型已在 AMD 和自研芯片设计里给出可验证的改进： 11 月 18 日博客写到，在已高度优化的基线上，AMD 旗舰 GPU IP 看到最高约 14% 的功耗、性能和面积改善，部分改动已经送去流片，另一些写入后续设计文件。OpenAI 还说，自研推理芯片 Jalapeño 的向量单元标准单元面积约下降 13%，矩阵单元约下降 10%，并已在硅上验证。公司同时在和 Synopsys 把模型接入现有 EDA 工具。这些百分比都来自 OpenAI 自己的报告。原链接

腾讯称 WorkBuddy 日活超过 1000 万： 11 月 18 日发布的 2026 年第三季度业绩里，腾讯写 WorkBuddy 按大模型 token 消耗计，已成为中国使用量最大的 AI 产品，日活超过 1000 万，这些用户每天合计消耗超过 100 万亿 tokens，企业采用也在快速增加。马化腾在致辞里用了同一口径。英文官方稿中没有写「近 7 日收入年化超过 5 亿美元」，这一数字只出现在部分媒体转述里，这里不以官方数字采用。原链接

Nginx 被披露两个未认证即可远程执行代码的 HTTP/2 漏洞： Wiz、Ikotas Labs、Metnir、Rapid7 和 Xint 分别发现 CVE-2026-123633 和 CVE-2026-123007，CVSS 4.0 均为 9.2，前提是服务器启用了 HTTP/2。Wiz 写道，其中整数下溢可追溯到 2015 年的 NGINX 1.9.5，影响范围到 1.31.8。他们还演示了在只提供静态文件、没有后端应用和第三方模块的情况下完成代码执行。同批安全更新还包括 HTTP/3、DNS 解析器和邮件代理等修复。F5 已发布修复，官方建议尽快升级。若暂时不能升级，Wiz 建议先关闭 HTTP/2。原链接 原链接
