人物

Tw93 @HiTw93

主题：给 Agent 一份「别做 AI Slop」的产品 Review 清单 原链接

他写了一篇站在产品工程师视角的长文，回答怎么用 AI 做出不那么丑、还能用的产品。优先级写得很死：先能解决问题，再易用，好看只是锦上添花。后面列了一大段可直接丢给 Agent 的 Review 清单，包括用小白身份走主链路、文案本地化、能用交互说清就少加说明、危险操作才二次确认、一页只留一个强调色、灰色用偏暖的灰、字号尽量不超过四种等。

我的看法：这比再发十张「AI 设计提示词」有用，因为它把品味拆成可检查的工程约束；真要落地，还得看团队愿不愿意让 Agent 对照清单改仓库，而不是只拿来当审美鸡汤。

Cos(余弦) @evilcos

主题：黑客怎么轻易毒掉你的电脑，以及反杀面试骗子 原链接

他强烈推荐技术人去看一篇复盘，讲黑客如何轻易让电脑中毒。同一帖还附了一段黑色幽默：对方假面试套资料时，直接丢钱包地址让对方先打 1000U 验证诚意，对方真打了就拉黑。互动很高，说明安全焦虑和骗局题材仍然好卖。

我的看法：复盘值得读，反杀段子别当真成操作手册；真遇到钓鱼面试，优先断链取证，别把自己卷进洗钱灰区。

宝玉 @dotey

主题：Agent 也要交截图作业，顺手拆 Omni 与 IPO 账 原链接

他把当年管粗心员工的招数搬到 Agent：PR 必须带功能截屏，现在则要求 Agent 任务结束后自测并生成效果截图，很多 bug 在截图时就被自己发现修好。同日他还细拆了 Gemini Omni 1.2 Flash 的定价与能力，以及 Ramp 数据下的 Anthropic 估值讨论（详见 AI 资讯）。另外吐槽做 DeepSeek Harness 插件还得自己写自动更新 原链接 。

我的看法：「截图即验收」是目前最便宜的 Agent 质检；自动更新这种脏活会反复出现，说明插件生态还远没到平台替你包圆的时候。

CuiMao @CuiMao

主题：智算中心旁边开商 K，以及 GTA6 会被模型逼上 PC 原链接

最高赞那条说，去乌兰察布智算中心边上开一家装修和服务都到位的商 K，是刚需。另一条调侃 GTA6 会很快上 Steam：大模型跨平台移植太强，指不定有人用 mythos 级模型直接破解，R 星越锁 30 帧群众越想上 DLSS 原链接 。另有一条只喊「季逸超！我开心！」原链接 。

我的看法：商 K 梗把「算力基建＝人货场」写得很准；游戏移植那条是情绪宣泄，别当成发行时间表。

Orange AI @oran_ge

主题：一张图讲 AI 编程经济学，再叠 ANT 上市魔咒 原链接

他发「一张图理解 AI 编程经济学」。随后盯 Anthropic IPO：如果这次 A 社上市真失败，ANT／蚂蚁这个代码可能被诅咒，上次蚂蚁上市失败也在 11 月 原链接 。另有一条短评「ai 游戏才刚开始就价值泯灭了」原链接 。

我的看法：经济学那张图适合当讨论起点；把 IPO 成败归因到代码魔咒很好玩，但定价权仍在买家和市场，不在梗。

图拉鼎 @tualatrix

主题：删掉 VS Code，再买一台 iPad mini 原链接

继上周宣布不再用终端后，他今天把 VS Code 也删了，称它是自己 AI 编程的初恋，最早在上面用 Copilot 补全，现在已经不需要。另一条是取消 iPhone Duo 订单后改买 iPad mini，女儿以为 mini 是给小孩的抢先开箱 原链接 。

我的看法：弃 IDE 叙事适合已经把工作流迁到 Agent／云端的人；多数人删了编辑器只会少一个回退面，别跟风表演。

yetone @yetone

主题：宣称已经把 Grok 训出来了 原链接

他发图说「我已经把 Grok 训出来了」，互动不低。帖子本身几乎没有方法、数据或评测细节，更像成果炫耀或梗图。

我的看法：没有训练配方和对照评测，就当趣味帖；真要跟进，等仓库、loss 曲线或可复现脚本，而不是点赞截图。

plantegg @plantegg

主题：定位问题三板斧，外加福报厂勒紧大龄员工 原链接

周五掏心窝：定位问题靠好奇心、工具／知识积累、以及简单稳定的复现；并说现在可用 AI 补过去老工程师才有的工具积累。同日写福报厂裁大龄的路径：先给 3.5，再扣年终和股票，再砍到 3.25，一步步希望你自己走 原链接 。另有中美工程师分层长文 原链接 。

我的看法：三板斧比鸡汤实在；裁员路径写得很具体，可当求职风险提示，但别把单厂手段直接外推成全行业定律。

Barret李靖 @Barret_China

主题：同事每天最多的工作，是把消息转发给 AI 原链接

他转述同事：对接客户多，大部分时间是理解需求再转发给自己的 AI，AI 在旁排队处理。表面轻松，背后是写码、Review、测试环境，以及把业务上下文、代码、文档、会议和聊天记录汇成中台，让工作像流水线转起来。结论是工程师时间正从埋头写码，转向理解需求、搭环境和组织上下文。

我的看法：这是个人 Agent 落地后最诚实的岗位描述；真要可复制，难点不在「会转发」，而在权限、审计和坏上下文污染。

Sac @Saccc_c

主题：开源近 20 万浏览的 AnliBili 站点与制作 Loop 原链接

他宣布开源 AnliBili 网站代码和核心制作流程。站点已有 10＋类别、2000＋视频，并按停留与收藏做推荐。同时在 Teamily 建「Sac的 AI 交流群」，公开整理评论→筛选视频→分类上线的 Loop、相关 Prompt 和代码，还强调群里可 @Agent、共享 Loop、多人多模态改稿。

我的看法：把流量站连同生产 Loop 一起开源，比只丢前端仓库诚恳；版权和推荐数据从哪来，开源帖里说得少，自己用前要核清楚。

SagaSu @sujingshen

主题：magpie 一晚上落后 90＋版本 原链接

他抱怨 magpie 更新频率太恐怖，一晚上没用就落后 90＋版本，并问对方是不是已经全自动编程。帖子短，但点中了中文圈对「高频发版个人项目」又羡慕又焦虑的情绪。

我的看法：版本号刷得快不等于产品前进；若没有 changelog 和稳定性承诺，追随成本会高于收益。

小小东 @xiaoxiaodong

主题：Claude 重置卡技巧，以及要开源插画 skills 原链接

他说一周拿到两张 Claude 重置卡：故意让 Ultra 掉回 Pro 再慢慢升，还分享 KYC 拍护照的注意点。另一条宣称要用 Opus 5.5 和 GPT-image 2.6 整一波开源插画 skills 原链接 。

我的看法：重置卡攻略属于灰区操作，账号风险自负；开源插画 skills 若真放出提示词和评测，会比晒图更有信息量。

郭宇 @turingou

主题：抽九管血之后还在 Vibe Coding 原链接

他一天没吃东西，抽了 9 管血，街边点了一大碗 pasta。下午在书房 Vibe Coding，困到不行，并感叹失血原来会让人特别想睡 原链接 。

AI 资讯

Google 发布 Gemini Omni 1.2 Flash，视频生成首次 GA 原链接

11 月 5 日推出，Gemini API 与 Google Cloud 正式可用。单条最长 15 秒（1.1 为 10 秒），720p 约每秒 0.07 美元、较 1.1 降价约 30%，支持多轮对话改同一条视频，并加强参考图／短动作一致性。普通用户可在 Google Vids 生成 15 秒片段，Gemini App 向 AI Ultra 滚动推送。官方帖 原链接

Anthropic IPO 估值讨论下修到约 1.2 至 1.3 万亿美元 原链接

在科技股抛售背景下，部分投资者认为此前 1.5 万亿都偏乐观，Bloomberg 转述讨论区间约 1.2 到 1.3 万亿，早期曾传 2 万亿。Ramp 数据显示企业 token 用量仍涨，但 8、9 月支出几乎不动，侧面给「收入高速增长」叙事降温。尚未最终定价，也不等于确定延期。

DeepMind：AI agent 在遗留 RSA-1024 上挖出两处弱点 原链接

11 月 6 日官方称，在人类指导下模型发现遗留 1024 位 RSA 的两处重大弱点，并强调现代 2048 位及以上不受这些具体利用影响。外媒转述包括签名伪造相关发现，以及更便宜的相关模数批量分解；部分场景号称相对旧方法提速约 1600 倍。真正信号是密码学假设的压力测试节奏被 AI 拉快，而不是今天的网银立刻不安全。

Qwen 发「The becoming begins」预热，北冥有鱼留白 原链接

官方只发一句 The becoming begins. 配庄子「北冥有鱼 其名为 _」海报，浏览与转发极高。社区普遍读成 Qwen 4 将至，但无型号、无参数、无权重、无 API 名，记作预热即可，不算发布。
