# 整理报告与草稿

先读仓库 `AGENTS.md` 和 `README.md`「四个功能 Skill」「导入与内容整理」；整理日报／周报时再读「日报与周报」。输入为用户提供的素材或已有草稿，采集由用户负责。

## 整理

1. 确定本期类型、日期、素材路径和允许修改的范围。尚未导入的素材先使用 `report-import`；已有完整草稿且用户只要求预览时，直接转到 `report-preview`，不重新整理。
2. 读取本期所有指定资料与现有 `draft.md`，保留原始资料。已有人工编辑时以当前稿件为基础，先在本期 `.local/` 工作目录备份，再按本次要求调整。
3. 按内容分类、重排条目、拟栏目和展示标题。默认逐条保留正文措辞、数字、链接、引用、代码、表格、图片及限定条件，保留原文标题与来源。可另拟展示标题；疑似重复、分类不明或资料冲突写进整理说明，等待用户决定，不自行删减。
4. 日报／周报将结果写入本期 `draft.md`：一个一级标题表示本期名，二级标题划分栏目，三级标题标记条目。保留本地图片引用；完整格式见 README。周报必须从私人草稿区整理，不能直接写正式 HTML。外部链接在页面上会显示为外链图标加「原链接」，并在新标签页打开。草稿可以继续写裸网址或 Markdown 链接；不要为了让读者看到完整 URL，把网址再贴成可见正文。页内锚点和本地图片引用保持原样。
5. 对照原始资料和修改前草稿检查每个条目，核对正文及引用未丢失。周报将分类、顺序、标题变化和待决定事项记入本期 `review.md`；日报／报告可在交付说明中列出。报告只在用户明确要求整理时修改，并保留现有设计。

## 编辑授权

- 默认“整理”只包含分类、重排和拟标题。删减、去重、合并正文、改写、概括或补写导读／摘要／推荐理由，均需用户明确授权；授权仅应用于指定部分。
- `weekly:draft` 会自动删除完全重复条目。仅在用户明确要求该命令或授权去重时调用 `npm run weekly:draft -- YYYY-MM-DD`；覆盖受保护草稿前需获得覆盖授权、保留备份，再加 `--replace`。普通整理直接编辑草稿即可。
- 来源核对由用户处理。保留原有来源与不确定性，不补造事实、链接或采集新消息。

## 完成边界

交付草稿路径、整理说明和待用户决定的事项。只要求整理时到此结束；要求继续预览时调用 `report-preview`。本技能不定稿、提交或推送，周报由用户查看最新预览并确认后才能发布。
